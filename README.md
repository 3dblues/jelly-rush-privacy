# Jelly Rush privacy policy

1. Replace `[DEVELOPER NAME]` and `[CONTACT EMAIL]` in `index.html`.
2. Upload `index.html` and `.nojekyll` to the root of a public GitHub repository.
3. Open **Settings → Pages** in the repository.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch and `/ (root)`, then save.

The public URL will usually be:

`https://YOUR-USERNAME.github.io/REPOSITORY/`

Add that URL to **Google Play Console → Policy and programs → App content → Privacy policy** and place the same link inside the app.
